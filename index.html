Hamamcan Uploader

Privacy PolicyTerms of UseKVKK (Türkçe)

Hamamcan Uploader is a private tool that runs on its owner's own computer. It adds captions to short comedy videos and uploads them to the owner's own channel, Hamamcan, on YouTube. It has no other users and is not offered to the public.

This tool uses YouTube API Services.

Privacy Policy

Last updated: November 5, 2026

YouTube API Services and Google

This tool uses YouTube API Services. Google's handling of data is described in the Google Privacy Policy.

Information accessed, stored and used

The tool is authorized with OAuth 2.0 on the owner's own Google account and uses two permissions:

  • youtube.upload: to upload videos, with their title, description, tags and privacy status, to the owner's channel.
  • youtube.readonly: to read the channel name and the status of videos it uploaded.

It does not collect information about viewers or any other person.

Storage on the device

The authorization token, videos and upload records are stored only on the owner's computer. The tool has no server and does not use cookies. Authorization tokens are kept only while access is needed. Channel and video status information read from the API is not retained for more than 30 days.

Sharing

Information obtained through YouTube API Services is sent only to YouTube, to complete an upload. It is not sold or shared with anyone else. The tool shows no third-party content or advertising.

Revoking access and deleting data

Access can be revoked at any time through the Google security settings page. The tool also has a command that revokes its access and deletes the token and the data it read from the API. Stored data is deleted within 7 days of a revocation or a deletion request. This does not affect data held by YouTube; videos on the channel are managed in YouTube Studio.
